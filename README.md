Diabetes Readmission Prediction:

A machine learning application that predicts the likelihood of early hospital readmission for diabetic patients. The project integrates a trained machine learning model with a Flask backend and an Angular frontend, supported by a GitHub Actions CI/CD pipeline and GitHub Pages deployment.
Dataset: Diabetes 130-US Hospitals for Years 1999–2008

Dataset characteristics:
1. Approximately 101,766 hospital encounters.
2. 50 original data columns.
3. The target variable is readmitted.
4. The dataset includes three original readmission categories: <30, >30, and NO.
